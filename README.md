# LearnerModel

A structured full-stack learning dashboard built with React + Vite. Interactive modules with live demos, quizzes, code examples, and interview prep.

## Modules

1. **Node.js Core Fundamentals** — Event Loop, Modules, Core APIs
2. **Express.js & Middleware** — Routing, Middleware, Auth, REST API Design
3. **Databases & ORMs** — MongoDB, PostgreSQL, Redis, Prisma, Connection Pooling
4. **Testing & Debugging** — Jest, Supertest, Integration Tests, Debugging
5. **Deployment & DevOps** — Docker, PM2, nginx, CI/CD, Monitoring
6. **TypeScript with Node** — Types, Interfaces, Generics, tsconfig, Zod Validation

## Tech Stack

- React 18 + Vite 5
- Node.js v24+ (ES modules)

## Scripts

```bash
npm install
npm run dev      # Development server
npm run build    # Production build
```
